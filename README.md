# Power BI DAX Practice Questions

## About This Repository
This repository contains 100 Question on my DAX practice questions and solutions as I learn Power BI and improve my data analytics skills.

## Topics Covered
- Basic DAX functions
- IF, AND, OR, and SWITCH
- SUMX, AVERAGEX, COUNTX, MINX, and MAXX
- CALCULATE and FILTER
- ALL, ALLSELECTED, and ALLEXCEPT
- REMOVEFILTERS and KEEPFILTERS
- Row context and filter context
- Sales, profit, discount, and net sales calculations

## Objective
To strengthen my understanding of DAX and practice business scenarios commonly used in Power BI reports and dashboards.

## Tools Used
- Microsoft Power BI
- DAX (Data Analysis Expressions)
